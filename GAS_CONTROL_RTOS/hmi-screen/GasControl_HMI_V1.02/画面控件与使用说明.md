# 大彩串口屏画面工程说明

本目录是可由 VisualTFT 3.0 打开和编辑的大彩工程，适配 `DC10600PM101`、1024×600 横屏、GBK 编码和 MCU 的 SCI9 115200、8N1 通讯。工程版本为 V1.02。

## 画面结构

| 画面ID | 文件 | 用途 |
|---:|---|---|
| 0 | `Screen0.tft` | 启动主菜单，可进入实时监控、日志查询或参数设置 |
| 1 | `Screen1.tft` | 六瓶压力、状态、三类阀位、人工维护及系统安全启停 |
| 2 | `Screen2.tft` | 从主板 AT24C256 流式加载并滑动显示全部事件日志 |
| 3 | `Screen3.tft` | 从主板 AT24C256 流式加载并滑动显示全部常规日志，每条占两行 |
| 4 | `Screen4.tft` | 密码保护的11项可见运行参数输入和操作结果反馈 |
| 5 | `Screen5.tft` | 参数名、当前值、候选值及校验结果的独立逐项确认画面 |

主菜单和返回按钮使用 VisualTFT 官方“切换画面”按钮，切换动作由串口屏内部完成。切换画面不会停止 MCU 的压力轮询、自动换瓶、阀门计时或日志记录。

## 主菜单画面控件ID

主菜单画面ID为0。页面采用压力表、日志时钟和参数滑杆加锁三个线性图标，不在背景中保留操作说明小字。

| 控件ID | 控件类型 | 用途 |
|---:|---|---|
| 57 | 切换画面按钮 | 进入Screen1实时监控页 |
| 58 | 切换画面按钮 | 进入Screen2事件日志页 |
| 78 | 登录保护切换按钮 | 密码`243579`验证通过后进入Screen4参数设置页 |
| 115 | GBK文本控件 | 主菜单系统标题，默认显示“六瓶三阀气源控制系统”，可直接在VisualTFT中修改 |

## 打开和下载

1. 用 VisualTFT 3.0 打开 `GasControl_HMI_V1.02.tftprj`。
2. 确认工程中包含 `Screen0`～`Screen5` 六个画面，启动页为 `Screen0`。
3. 执行“编译”，确认没有控件、字库或图片错误。
4. 使用大彩官方下载方式更新串口屏。
5. MCU 固件与本画面必须配套使用；固件中的实时监控目标画面ID必须为1。

工程源文件是正式交付内容。`output/` 和 `dciot_build/` 属于 VisualTFT 编译产物，必须以当前六页源工程重新编译后再下载。

压力质量为有效时，MCU清空红色层并把实际值写入青色层；压力质量为超量程时，MCU清空青色层并把
实际值写入红色层；压力无效或陈旧时，MCU清空红色层并在青色层显示`--`。每次切换均严格先清空
非目标颜色层、再写目标颜色层，避免两个透明控件同时存在数字造成重影和混色。超量程实际值只用于
诊断显示，不参与自动供气状态机。

控件72～77共用 `images/Gas_Cylinder_Highlight.icon`。图标控件放在压力、状态、阀位和按钮控件的下层，
因此高亮只改变卡片视觉层级，不会遮挡实时数据或占用按钮触摸区域。状态与帧的固定关系如下：

六个控件使用透明显示，不与背景图片融合，并关闭自动播放。画面只显示MCU通过 `B1 23` 指令指定的帧，
防止共享图标复制其他气瓶卡片的背景，也防止状态不变时图标自行换帧。
`Gas_Cylinder_Highlight.icon` 的32位像素按 `ARGB` 字节顺序存储，禁止改为 `BGRA`，否则绿色会显示为紫色，
红色会显示为青绿色。

| 气瓶状态 | 帧索引 | 画面效果 |
|---|---:|---|
| 使用 | 1 | 绿色高亮边框、绿色状态区域和轻微绿色底色 |
| 低压警告 | 2 | 红色高亮边框、红色状态区域和红色底色 |
| 初始化、待测试、待用、低压待换、停用 | 0 | 完全透明，不改变普通卡片外观 |

MCU指定图标帧的完整报文格式为：

```text
EE B1 23 页面ID(2B) 控件ID(2B) 帧索引(1B) FF FC FF FF
```

## 事件日志画面控件ID

事件日志画面ID为2，表格只接收事件类型记录。

| 控件ID | 类型 | 用途 |
|---:|---|---|
| 61 | 弹起按钮 | 请求主板筛选并流式加载全部事件日志 |
| 62 | 四列数据记录控件 | 显示时间、气瓶、状态变化和变化时压力 |
| 63 | 文本控件 | 显示扫描进度、已加载条数、日志更新、时间无效或读取错误 |
| 64 | 切换画面按钮 | 返回主菜单，不上传业务事件 |
| 69 | 切换画面按钮 | 切换到画面3常规日志，不上传业务事件 |
| 116 | GBK文本控件 | 事件日志页面标题，默认显示“事件日志”，可直接在VisualTFT中修改 |

控件62配置为四列表格，一屏显示15行，最多在SDRAM中保存1017行，单行96字节。固件从日志快照最新端向旧端扫描，匹配事件类型后立即追加到表格底部，因此最新事件始终位于顶部，向上滑动可查看更早记录。

事件日志仅在气瓶业务状态发生变化时生成；排气阀、测试阀和刷新按钮操作本身不会生成事件。串口屏RTC时间无效时主板暂停写入新日志。

## 常规日志画面控件ID

常规日志画面ID为3，表格只接收半小时常规记录。

| 控件ID | 类型 | 用途 |
|---:|---|---|
| 65 | 弹起按钮 | 请求主板筛选并流式加载全部常规日志 |
| 66 | 两列数据记录控件 | 统一显示时间、压力行和状态行，一屏20行 |
| 67 | 文本控件 | 显示扫描进度、已加载条数、日志更新、时间无效或读取错误 |
| 68 | 切换画面按钮 | 返回主菜单，不上传业务事件 |
| 70 | 切换画面按钮 | 切换到画面2事件日志，不上传业务事件 |
| 71 | 保留ID | 不再创建控件，避免两个数据表独立滑动导致时间与内容错位 |
| 117 | GBK文本控件 | 常规日志页面标题，默认显示“常规日志”，可直接在VisualTFT中修改 |

控件66覆盖完整表格区域，列宽为22%时间和78%内容，一屏20行对应10条逻辑记录。最多保存2034个物理行，即1017条常规日志，单行128字节。每条常规记录先追加“时间＋压力”行，再追加“空时间＋状态”行，两行在同一控件内整体滑动，不会错位。

AT24C256是两类日志的唯一持久化来源，串口屏只临时显示查询结果，避免重复保存和额外Flash擦写。

## 参数设置与独立确认画面控件ID

参数设置画面ID为4。主菜单控件78使用VisualTFT登录保护，固定密码为`243579`；验证通过后切换到

| 控件ID | 类型 | 参数或操作 |
|---:|---|---|

| 84～88 | 文本输入 | 强吸合时间、低压确认时间/样本数、关阀等待和开阀等待 |
| 89 | 文本输入 | 手动排气时间，单位秒，允许3.000～65.535，支持三位小数 |
| 90 | 文本输入 | 测试阀最长开启时间，单位秒，允许5～60 |
| 93 | GBK文本 | 输入、校验、逐项确认和EEPROM保存结果提示 |
| 97 | 弹起按钮 | 建立全部默认候选值并自动打开画面5，确认前不生效 |
| 98 | 切换画面按钮 | 返回主菜单并结束当前编辑会话 |
| 108 | 画面5弹起按钮 | 确认并应用；写EEPROM成功后立即应用候选参数 |
| 109 | 画面5弹起按钮 | 返回修改；恢复当前值且不改变EEPROM和运行参数 |
| 110 | 画面5 GBK文本 | 显示本次待确认参数名称 |
| 111～112 | 画面5文本 | 分别显示当前值和规范化候选值 |
| 113 | 画面5 GBK文本 | 显示可确认、格式错误、范围错误或关系错误说明 |
| 118 | 画面4 GBK文本 | 运行参数设置页面标题，默认显示“运行参数设置”，可直接在VisualTFT中修改 |

文本输入控件启用系统数字键盘，使用控件类型`0x11`的`B1 11`帧上传ASCII值。低压警告压力限定
1.5～5.0 MPa，人工排气限定3.000～65.535秒，测试阀超时限定5～60秒；越界文本被拒绝并恢复为当前值。
画面不显示回差释放压力和压力数据新鲜度；固件保存时将回差设置为切瓶压力加0.100 MPa，并把压力
数据新鲜度固定为2500 ms，然后再按完整13项关系校验和保存。待用最低压力输入框下方提示为
“不低于切瓶压力+0.1MPa”，与隐藏回差的自动补齐规则保持一致。
输入值在输入框内水平和垂直居中。用户修改控件80～90后，`main.lua`立即调用
`change_screen(5)`切换到独立确认画面；控件108写入并应用，控件109返回修改。控件97恢复默认也
进入相同确认阶段。画面4没有保存、确认和取消按钮。MPa输入支持整数和最多三位小数，`20`、`20.0`
及`20.00`均规范化显示为`20.000`。参数保存无需停止自动运行。
系统模式文本94和开关99位于实时监控页，便于人员结合压力、状态和阀位反馈进行操作。开关值0请求自动运行，值1立即安全停止并关闭全部18路阀门。MCU使用大彩`B1 10`按钮状态指令在模式变化和周期刷新时回写实际状态，不把屏幕本地状态作为控制依据。运行中应用
不会中断已经进入机械关阀/开阀阶段的切瓶流程；外部CAN和RS485参数提交仍要求系统停止且阀门全关。

查询过程使用以下大彩官方指令：

```text
清空表格：EE B1 53 页面ID(2B) 控件ID(2B) FF FC FF FF
添加一行：EE B1 52 页面ID(2B) 控件ID(2B) 分号分隔的GBK文本 FF FC FF FF
```

事件行包含四个字段；常规压力行和状态行都包含“时间；内容”两个字段，状态行的时间字段为空。两个表格都设置为新行追加到底部，固件按快照从新到旧发送，使最新逻辑记录位于顶部。

查询每扫描32条原始日志就更新一次进度。如果扫描期间EEPROM追加新日志，固件立即停止使用旧快照，保留已显示行并显示“日志已更新”；用户再次点击刷新即可加载最新完整快照。

## 日志内容说明

常规记录每30分钟生成一次，在画面3拆成以下两行：

```text
控件66：08-22 10:30;压力:1#3.00 2#4.00 3#5.00 4#6.00 5#8.00 6#9.00 总压:9.00 MPa;
控件66：;状态:1#使用 2#待用 3#待用 4#待用 5#待用 6#待用;
```

事件记录在任一气瓶状态变化时生成，在画面2显示为一行：

```text
2026-08-22 10:31:02;1号;低压警告->低压待换;1.180 MPa;
```

屏上实际报文中的中文使用固定GBK字节，英文分号只作为数据记录控件的字段分隔符。

## 编码和字库

- 状态、阀位和日志中文全部使用GBK编码，文本控件设置 `encode="1"`。
- 工程复用已验证的GBK字库；不要把中文控件改成UTF-8或纯ASCII。
- 固件发送固定GBK字节，不依赖编译电脑的源文件编码。
- 事件数据记录控件一屏使用15个可见行；常规统一两列控件一屏使用20行，对应10组双行记录。

## 操作原则

- 进气阀没有人工按钮，只由自动换瓶状态机控制。
- 使用或低压警告状态下，固件拒绝本路排气阀和测试阀开启。
- 停用时本路三个电磁阀全部关闭。
- 测试阀和排气阀按当前运行参数自动关闭，默认分别为60秒和5秒。
- 使用状态气瓶显示绿色卡片高亮；低压警告状态气瓶显示红色卡片高亮；其余状态不高亮。
- 操作人员应以25～48号状态和阀位文本为准；51～56号测试合格开关和99号整机模式开关由MCU回写，最终显示以程序实际状态为准。
