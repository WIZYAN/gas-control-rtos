# 使用本手册前

:::warning 重要安全边界
本手册说明控制系统操作，不替代钢瓶、减压阀、管路、泄压和检漏等现场安全规程。涉及机械换瓶、带压检查或检漏时，必须由受训人员按现场批准程序执行。
:::

- 系统上电后固定进入自动控制，不提供人工“停止系统/恢复自动”按钮。
- 全系统最多只允许一只气瓶供气；同一路进气阀开启时，排气阀和测试阀必须关闭。
- 停用状态下，该瓶进气、排气和测试三阀始终关闭。
- 压力显示“--”代表数据无效或未更新，不应当作零压力。超量程值使用红色显示。
- 界面状态以MCU回写为准；按钮初始外观不能替代实际阀位确认。

# 气瓶状态、颜色和压力显示

| 状态 | 画面含义 | 操作要点 |
| --- | --- | --- |
| 初始化 | 等待有效压力或重新判定 | 完成压力采集后转入低压待换、待测试或待用 |
| 待用 | 测试通过且压力合格，可自动投入 | 保持三阀关闭，等待系统选为工作瓶 |
| 使用 | 当前工作瓶，绿色卡片 | 进气阀开启；禁止人工排气和测试 |
| 低压警告 | 工作瓶压力偏低，红色卡片 | 仍继续供气，准备合格备用瓶 |
| 低压待换 | 非工作瓶压力不足或已退出供气 | 换瓶/恢复压力后重新测试 |
| 待测试 | 压力已合格，等待人工测试确认 | 完成排气、测试并设置为已通过 |
| 停用 | 该路退出运行 | 三阀全关，解除停用后重新初始化 |

:::info 颜色规则
绿色只表示当前“使用”瓶；红色只表示当前工作瓶的“低压警告”。其他状态不因压力低自动显示红色卡片。
:::

- 正常压力使用青色显示；超过压力合法上限但仍可诊断显示时使用红色。
- 无有效数据或数据过期显示“--”，系统不会把未知压力用于自动选瓶。
- 默认待用最低压力1.500 MPa；默认低压警告压力2.000 MPa；默认切瓶压力1.200 MPa。

# 日常运行与自动换瓶

## 一用五备

- 系统按1→2→3→4→5→6→1的环形顺序寻找下一只合格待用瓶。
- 候选瓶必须处于待用、压力有效、测试已通过，并且排气阀和测试阀均关闭。
- 上电后若没有工作瓶，系统会按顺序选择第一只合格待用瓶投入使用。

## 默认换瓶条件

| 阶段 | 系统行为 | 现场人员关注点 |
| --- | --- | --- |
| 工作瓶低于2.000 MPa | 进入低压警告但继续供气 | 确认备用瓶压力和测试状态 |
| 达到或低于1.200 MPa | 开始低压持续时间和独立样本确认 | 观察压力是否稳定，避免瞬时波动 |
| 确认完成 | 先关闭旧瓶，等待500 ms | 旧瓶进气阀应显示关闭 |
| 投入新瓶 | 打开新瓶，等待500 ms后确认 | 新瓶显示使用，绿色卡片 |
| 无合格备用瓶 | 保留旧瓶供气并产生无备用瓶报警 | 立即准备并测试备用瓶 |

:::success 换瓶确认
换瓶完成后，应确认全系统只有一路进气阀显示开启，新瓶为“使用”，旧瓶为“低压待换”，且没有第二只绿色卡片。
:::

# 气瓶更换与重新投入

:::danger 安全边界
本节只说明控制系统操作。机械拆装、隔离、泄压和检漏必须执行现场批准的钢瓶更换规程。
:::

| 步骤 | 操作 | 通过标准 |
| --- | --- | --- |
| 1 | 确认目标瓶不是当前使用瓶，将该路切换为已停用 | 该瓶三类阀位均显示关闭 |
| 2 | 按现场规程隔离、泄压、更换并检漏 | 机械连接和检漏合格 |
| 3 | 解除停用，等待压力重新变为有效 | 状态由初始化进入低压待换或待测试 |
| 4 | 必要时执行人工排气 | 排气阀到时自动关闭 |
| 5 | 打开测试阀完成检测，再次点击关闭 | 测试阀显示关闭；最长开启受5～60分钟限制 |
| 6 | 确认检测合格后，把测试合格切换为已通过 | 压力合格时进入待用 |
| 7 | 返回监控确认阀位和状态 | 待用瓶三阀关闭，可参与自动选瓶 |

若“已通过”请求被拒绝，先检查：压力是否有效且不低于待用最低压力、是否已进入待测试、是否仍有人工阀门开启，以及该瓶是否处于停用。

# 人工排气、测试阀与停用

| 状态 | 人工排气 | 测试阀 | 测试合格 |
| --- | --- | --- | --- |
| 初始化 | 允许 | 允许 | 拒绝通过 |
| 待测试 | 允许 | 允许 | 允许设置为通过 |
| 待用 | 允许 | 允许 | 可改为不通过，随后退出待用 |
| 使用 | 禁止 | 禁止 | 禁止修改 |
| 低压待换 | 允许 | 允许 | 压力恢复后先进入待测试 |
| 低压警告 | 禁止 | 禁止 | 禁止修改 |
| 停用 | 禁止 | 禁止 | 自动撤销 |

- 人工排气为瞬时操作，默认5.000秒；允许设置3.000～65.535秒。
- 测试阀为开关操作，再次点击可提前关闭；默认最长10分钟，允许设置5～60整分钟。
- 任一路测试阀请求会联动总测试阀；总阀确认后再打开分路测试阀。
- 多路分支测试阀可同时测试；最后一路结束后总测试阀才关闭。
- 人工阀门开启期间，该瓶不能被自动选为工作瓶。

:::warning 时间参数生效规则
修改排气时间或测试阀最长开启时间后，新值从下一次开阀开始生效；已经开启的阀门继续使用本次启动时确定的截止时间。
:::

# 测试合格开关与重新测试

- 上电时六只气瓶的测试合格标志默认均为未通过。
- 气瓶进入低压待换或停用时，系统自动撤销原测试通过结论。
- 低压待换瓶压力恢复到1.500 MPa以上后，需要连续3个独立有效样本才进入待测试。
- 只有待测试状态允许设置为已通过；请求不满足条件时，MCU会拒绝并把开关回写为实际状态。
- 待测试同时满足压力有效、压力不低于待用最低压力、测试通过后进入待用。
- 待用状态改为未通过后，该瓶进入待测试并退出自动选瓶集合。

| 现场现象 | 优先检查 |
| --- | --- |
| 测试合格开关自动弹回 | 状态不是待测试、压力不足/无效、仍处于停用 |
| 压力恢复但仍低压待换 | 是否已连续获得3个独立有效样本 |
| 待测试无法进入待用 | 测试是否完成、阀门是否关闭、合格开关是否已被MCU接受 |
| 待用瓶突然退出待用 | 压力是否降到1.500 MPa以下，或合格结论是否被改为未通过 |

# 日志条件查询（Screen6）

{{screen:6}}

Screen6：时间范围、气瓶和进入状态筛选

- 日期固定输入8位YYYYMMDD，时间固定输入6位HHMMSS。
- 修改任一合法日期或时间后，系统自动启用“限定时间”。查询范围包含开始和结束边界。
- 例如20260829 000000至20260830 235959，只返回8月29日和8月30日的记录。
- 气瓶编号和进入状态使用整块下拉菜单直接选择；“重置条件”恢复全部时间、全部气瓶和全部状态。
- 事件日志支持时间、气瓶和进入状态组合筛选；常规日志只按时间范围筛选。

:::danger 输入错误
开始时间晚于结束时间时，系统提示“时间范围错误”且不会读取EEPROM日志。格式错误时先修改对应输入框。
:::

# 清除全部日志（Screen7）

{{screen:7}}

Screen7：二次确认、当前数量和清除状态

:::danger 不可恢复
确认清除会永久删除事件日志和常规日志。执行前应完成必要的数据抄录或导出，并确认不再需要现场追溯。

- 运行参数、CAN/RS485通信模式不会被清除。

# 系统时间、日志写入和查询边界

- 屏内RTC控件是日志时间来源。交接班、换瓶或故障排查前应核对系统时间。
- 事件日志在气瓶业务状态发生变化时写入；刷新页面或修改筛选条件不会制造事件。
- 常规日志按半小时周期记录压力和六瓶状态。
- 时间范围使用闭区间：开始和结束时刻本身都包含在结果中。
- 事件日志可继续叠加气瓶和进入状态条件；常规日志忽略这两个条件。

| 查询需求 | 推荐条件 |
| --- | --- |
| 查看某两天全部事件 | 开始日期第一天、000000；结束日期第二天、235959；全部气瓶、全部状态 |
| 查看某瓶何时进入低压警告 | 限定时间；选择气瓶编号；进入状态选“低压警告” |
| 查看某时段压力趋势 | 限定时间后查询常规日志；不需要设置气瓶和状态 |
| 查看最新记录 | 进入结果页后点击“最新页”，必要时再刷新当前类型 |

:::success 日期范围示例
输入20260829至20260830时，建议使用开始时间000000、结束时间235959。正确结果不会包含2026年8月28日的记录。
:::

# 常见异常与处理

| 现象 | 可能原因 | 建议处理 |
| --- | --- | --- |
| 压力显示-- | 传感器未响应、数据过期或通信异常 | 检查供电、地址、RS485接线；不要按零压力处理 |
| 压力足够但一直初始化 | 数据尚未稳定或测试未完成 | 等待有效样本，检查测试合格状态 |
| 备用瓶不进入使用 | 无合格待用瓶、人工阀门未关或正处于故障锁定 | 检查状态、压力、合格开关和阀位 |
| 低压警告不自动换瓶 | 未满足时间/样本确认或没有合格备用瓶 | 确认切瓶压力、持续时间、样本数及备用瓶 |
| 排气/测试按钮无动作 | 当前状态禁止、停用或人工阀门互锁 | 确认气瓶状态和阀位，禁止强制重复操作 |
| 参数修改被拒绝 | 格式、范围或参数关系错误 | 按Screen5说明修改；核对隐藏回差关系 |
| 日志时间无效 | 屏内RTC无效或5秒未读到有效时间 | 校准时间并观察是否恢复写入 |
| 日志清除失败 | AT24C256供电、WP或IIC异常 | 保留现场状态，检查WP、SCL、SDA后重试 |
| 多路阀位异常 | 输出互锁、线束或平台故障 | 立即按现场安全程序隔离气源并联系维护人员 |

:::danger 严重故障
阀门冲突、平台异常或切瓶开阀失败会进入内部故障锁定并关闭十八路分瓶阀和总测试阀。排障后通过重新上电恢复。
:::

# 巡检、交接班与维护记录

## 每班建议检查

- 核对系统时间、气瓶编号和现场钢瓶标签。
- 确认只有一只气瓶处于使用状态，且只有一路进气阀开启。
- 检查工作瓶压力、总管压力及红色低压警告。
- 确认至少一只压力合格、测试通过的待用瓶可供切换。
- 确认不需要操作的排气阀和测试阀均关闭，停用瓶三阀全关。
- 查询最新事件日志，核对换瓶、停用、测试和异常状态变化。
- 记录异常、参数修改、未完成维护项和交接人。
