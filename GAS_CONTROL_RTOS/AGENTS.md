# AGENTS.md

## 适用范围
本文件适用于本工程及后续基于 Renesas MCU 的嵌入式 C 工程。
目标是：**保持功能与硬件行为不变前提下，以最小认知成本提升可读性与可维护性**。

## 1. 总体目标

1. 可读性优先，优先保证理解成本低于“聪明设计”。
2. 不追求过度抽象，不做 C++ 式 OO 模拟。
3. 保持现有功能、时序、协议行为不变。
4. 重构以“去复杂化”为目标，不改变对外接口和外部依赖。

## 2. 编码原则（硬约束）

1. 全工程使用 **C99**。
2. 禁止动态内存分配（`malloc` / `free` 等）。
3. `struct` 嵌套原则上不超过 2 层。
4. 成员访问原则上不超过 3 层（包括 `ctx->a->b->c`、`a.b.c.d`）。
5. 仅保留有明确职责的模块；禁止新增无意义  
   `Manager / Service / Wrapper / Interface`（只做转发、无业务价值不允许）。
6. 避免把完整上下文贯穿到不需要它的函数；参数只传必要数据。
7. 参数命名要语义明确，能被快速搜索定位来源与用途。
8. 标志位必须定义清晰含义，注明作用范围（临时/状态/故障）。

## 3. 结构设计约束

1. 优先减少：
   - 深层结构体链路
   - 无意义转发层
   - 多余指针间接
2. 所有数据分层明确：
   - 配置数据（Config）
   - 运行态（State）
   - 临时变量（Temp / Local）
3. 关键参数必须具备：
   - 定义位置
   - 初始化位置
   - 修改位置
   - 读取位置
   - 使用位置  
   变更前需完成以上路径梳理。

## 4. 修改前必做流程（所有改动前必须执行）

1. 阅读目标模块实现与相关头文件。
2. 查找参数定义。
3. 查找参数初始化。
4. 查找所有写入点。
5. 查找所有读取点。
6. 梳理调用链（caller → callee → 子调用）。
7. 找出可能受影响的：
   - 关键时序（定时器/中断/任务周期）
   - 外设控制时序
   - 安全保护逻辑
   - 通信协议解析与交互行为
8. 明确“最小改动集合”和“回退策略”。

## 5. 函数与返回值规范

1. 函数应有明确返回值（至少成功/失败/错误码），不依赖隐式成功假设。
2. 外部接口必须可检查执行结果。
3. 局部静态函数在需要传播故障时也应返回状态码。
4. 调用方必须实现错误分支处理，不允许“忽略返回值”掩盖问题。

## 6. 变更执行规范

1. 不新增不必要的抽象层，仅在以下场景新增封装：
   - 明确复用 2 次以上且逻辑稳定
   - 显著降低重复代码与认知负担
2. 避免“对象拆分幻觉”：
   - 一个变量如果只在 A 和 B 之间透传，不进行修改且无额外语义，优先直接传递最小字段。
3. 统一使用扁平参数与明确职责函数，避免“把 context 往下层无限传递”。
4. 任何重构必须先确保以下两点：
   - 硬件访问行为不可变
   - 协议消息格式与时序不可变

## 7. 质量与验收要求（每次修改后必须检查）

1. 编译通过（目标平台可编译通过为先决条件）。
2. 结构体访问层级核查（禁止 >2 层嵌套、>3 层成员访问）。
3. 指针层级核查（禁止不必要多层间接）。
4. 运行行为核查：
   - I/O 时序未变
   - 安全保护逻辑未变
   - 外部通讯协议未变
5. 与上版本比对回归关键场景，确认无功能退化。
6. 若涉及关键流程，附上回归结论与边界情况说明。

## 8. 文档与版本要求

1. 代码提交必须同步更新关联文档（版本说明、流程文档、操作文档）。
2. 每次对外发布需更新版本号与变更点。
3. 文档里必须保留“变更范围 / 影响模块 / 验证方式”三项。

## 9. 风险与禁止项

1. 严禁：
   - 只为通过编译而修改行为
   - 仅为美观进行结构体重排导致时序变化
   - 在未确认的情况下引入全局状态
2. 如出现争议，优先保持行为稳定，宁可保留旧结构也不换接口。

## 10. 交付前最终清单

1. 关键参数数据流完整闭环已形成文档或注释说明。
2. 深层访问与无意义 wrapper 已清理（或给出待清理原因）。
3. 返回码与错误处理路径完整。
4. 编译与行为验收通过。
5. 版本号与文档同步更新。

## 11. 适用于新工程复用（建议）

本文件可直接作为后续 Renesas 工程的 `AGENTS.md` 模板使用。  
新工程可在此基础上补充以下两项：
- 业务特有时序规则（如周期、优先级、保护流程）
- 外设/总线栈的约束（如 SCI/CAN/Modbus 任务特性）
